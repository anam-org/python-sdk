    Creating Personas

    This guide will walk you through the process of creating and managing personas using the Anam Python SDK.

    Persona Structure

    A persona consists of two main components:

    1. The Brain data class
    2. The Persona data class

    Brain

    The Brain object contains the persona's system prompt, personality, and filler phrases.

    from anam_python_sdk.api.model import Brain

brain = Brain(
    system_prompt="You are a helpful assistant named Christian.",
    personality="Friendly and approachable",
    filler_phrases=["um", "ah", "well"]
)

    Persona

    The Persona object represents the basic information about a virtual persona. The preset field is the name of the persona preset to use. This determines your avatar choice of the persona.

    from anam_python_sdk.api.model import Persona, Brain

# ID is generated by the server
persona = Persona(
    name="Christian",
    description="A friendly AI assistant",
    persona_preset="eva",
    brain=None # We'll add the brain later
)

    Creating a Complete Persona

    To create a complete persona, combine the Persona and Brain objects:

    from anam_python_sdk.api.model import Persona, Brain

# ID is generated by the server
persona = Persona(
    name="Christian",
    description="A friendly AI assistant",
    persona_preset="eva",
    brain=Brain(
        system_prompt="You are a helpful assistant named Christian.",
        personality="Friendly and approachable",
        filler_phrases=["um", "ah", "well"]
    )
)

    Updating a Persona

    To update an existing persona, use the update_persona method of the AnamClient: Pass the persona_id of the persona you want to update. 

    from anam_python_sdk.api.client import AnamClient
from dotenv import dotenv_values

api_cfg = dotenv_values(".env")
client = AnamClient(cfg=api_cfg)

josh = client.get_persona_by_name("Josh")[0]
josh.name = "Joshua"
client.update_persona(persona = josh, persona_id=josh.id)
