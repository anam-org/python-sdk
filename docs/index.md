# Get Started with Anam using Python

Welcome to Anam's Python SDK documentation. This SDK provides tools for creating and managing virtual personas using the [Anam Lab](https://lab.anam.ai/login).

## What can you do with this SDK? 
- Create and manage your Anam personas in the lab programmatically.
- Customize persona behaviors and prompts. 
- Talk with your personas using WebRTC (**coming soon**).
