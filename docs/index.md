# Anam Python SDK

Welcome to the Anam Python SDK documentation. This SDK provides tools for creating and managing virtual personas using the AnamLab platform.

1. [Getting Started](getting-started.md)
2. [User Guide](user-guide/creating-personas.md)
3. [API Reference](api-reference/entities.md)
4. [Examples](examples.md)

## Features

- Create and manage virtual personas
- Interact with the AnamLab platform
- Customize persona behaviors and responses

## Installation

To install the Anam Python SDK, use:

```bash
pip install anam-python-sdk
```

```bash
poetry add anam-python-sdk
```

For more information on getting started, check out our [Getting Started](getting-started.md) guide.
