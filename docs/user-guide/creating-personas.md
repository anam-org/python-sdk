# Creating Personas

This guide will walk you through the process of creating and managing personas using the Anam Python SDK.

## Persona Structure

A persona consists of two main components:

1. The Brain object
2. The Persona object

### Brain

The Brain object contains the persona's system prompt, personality, and filler phrases.

```python
from anam_python_sdk.lab.entities import Brain

brain = Brain(
    system_prompt="You are a helpful assistant named Christian.",
    personality="Friendly and approachable",
    filler_phrases=["um", "ah", "well"]
)
```

### Persona

The Persona object represents the basic information about a virtual persona.

```python
from anam_python_sdk.lab.entities import Persona, Brain

# ID is generated by the server
persona = Persona(
    name="Christian",
    description="A friendly AI assistant",
    persona_preset="eva",
    brain=brain 
)
```


## Creating a Complete Persona

To create a complete persona, combine the Persona and Brain objects:

```python
from anam_python_sdk.lab.entities import Persona, Brain

# ID is generated by the server
persona = Persona(
    name="Christian",
    description="A friendly AI assistant",
    persona_preset="eva",
    brain=None # We'll add the brain later
)
```


## Updating a Persona

To update an existing persona, use the `update_persona` method of the AnamLabClient:

```python
from anam_python_sdk.lab.client import AnamLabClient
from dotenv import dotenv_values

api_cfg = dotenv_values(".env")
client = AnamLabClient(cfg=api_cfg)

persona.name = "Josh"
client.update_persona(persona)

```
