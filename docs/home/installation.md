# Installation
Getting started with the Anam Python SDK.
## Prerequisites

- Python 3.7 or higher
- `pip` or `poetry` to manage your Python packages.
- `python-dotenv` to load your API credentials from a `.env` file.

## Installation

Install the Anam Python SDK using `pip`:

```bash
pip install anam-python-sdk
```

or using `poetry`:

```bash
poetry add anam-python-sdk
```

## Configuration

1. Create a `.env` file in your project root directory.
2. Add your API credentials to the `.env` file:

```bash
ANAM_API_KEY=<your_api_key>
ANAM_API_SECRET=<your_api_secret>
```
